# Support

## Getting help

### Bug reports & feature requests

Open an issue on GitHub: https://github.com/Caezarr/bowimi-mcp/issues

When reporting a bug, include:

- MCP server version (commit SHA if running from source)
- Claude Desktop version (Help → About)
- Steps to reproduce
- Expected vs. actual behavior
- Relevant logs (redact your `BOWIMI_API_KEY` and any PII)

### Security vulnerabilities

**Do not open public issues for security bugs.**

See [SECURITY.md](./SECURITY.md) for responsible disclosure and contact details.
